SEMANA 06

Aplicaciones SPA con React

Prácticas de estructura HTML, composición de componentes con props y children, y desarrollo de una SPA en React con navegación y datos de usuarios.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Estructura HTML y composición con componentes

Se practicó la organización de una página con elementos semánticos de HTML, como section, nav, article, aside y footer. También se representó la interfaz mediante componentes anidados.

Props y children

Las props permiten transmitir datos a los componentes, mientras que children permite incluir contenido anidado. Ambos recursos ayudan a reutilizar componentes sin perder flexibilidad en la estructura.

Tema 02

SPA con React, Vite y Client-Side Rendering

Se trabajó con una aplicación de página única (SPA) creada con React y Vite. La navegación cambia las vistas desde el cliente y evita recargar el documento completo en cada sección.

Componentes y ciclo de vida del DOM

Se organizó la interfaz en componentes escritos con JSX, y se revisó el comportamiento del Client-Side Rendering (CSR) y las actualizaciones que React realiza en el DOM al cambiar de vista o de datos.

Tema 03

Navegación, API y estilos de interfaz

Se exploró la navegación entre vistas de inicio, lista y formulario, junto con la consulta de datos de usuarios desde una API de prueba usando axios. La lista resultante muestra información recibida de forma dinámica.

Estilado y validación

Se consideraron alternativas de estilado como CSS Modules, Tailwind e inline styles. El navegador y sus DevTools permiten comprobar la interfaz y revisar errores, solicitudes de red y rendimiento.

02

LABORATORIO

Actividades de laboratorio

Semana 06 · Actividad 01

Estructuras HTML con Props y Children

Descripción

Se construyeron estructuras de página con etiquetas semánticas de HTML y se practicó su composición a través de componentes. La actividad también mostró el paso de datos mediante props y la inclusión de contenido anidado con children.

Procedimiento

  1. Organizar las áreas principales de la página con elementos semánticos como nav, section, article, aside y footer.
  2. Separar las distintas partes visuales en componentes anidados.
  3. Pasar la información necesaria a los componentes mediante props.
  4. Componer contenido interno utilizando children y comprobar la estructura resultante.

Resultados

Se representaron una estructura semántica de página y una jerarquía de componentes anidados que muestra datos recibidos mediante props.

Semana 06 · Actividad 02

Desarrollo de una SPA y uso de una API con React

Descripción

Se desarrolló una aplicación frontend de página única con React, configurada con Vite y npm o pnpm. La práctica aplicó arquitectura de componentes con JSX, transmisión de datos con props, composición con children y estrategias de estilado como CSS Modules, Tailwind o estilos inline.

La aplicación incorpora navegación entre vistas, consulta de datos de una API y una interfaz de formulario. Se validó el Client-Side Rendering (CSR) observando la interacción y el ciclo de vida del DOM.

Recursos y herramientas

  • Node.js LTS (20.x o superior), con npm o pnpm.
  • Visual Studio Code con ES7+ React Snippets, React Developer Tools, Error Lens y REST Client.
  • Navegador moderno y DevTools: Network, Performance y Console.
  • Proyecto base con Vite, React, react-router-dom y axios.
  • API de prueba: JSONPlaceholder (jsonplaceholder.typicode.com/users) o DummyJSON (dummyjson.com/products).
  • Documentación: react.dev, reactrouter.com y axios-http.com.
  • Conexión a internet para consultar la API.

Procedimiento

  1. Preparar el entorno de desarrollo e iniciar el proyecto base de React con Vite.
  2. Crear componentes para las vistas de inicio, lista de usuarios y formulario, y configurar la navegación con react-router-dom.
  3. Definir componentes reutilizables y transmitir datos con props, utilizando children para componer su contenido.
  4. Consultar la API seleccionada con axios y representar los resultados en la vista de lista.
  5. Aplicar una estrategia de estilos y probar la interacción y el renderizado desde el navegador.
  6. Revisar solicitudes, errores y rendimiento con las DevTools para validar el comportamiento del CSR y del DOM.

Resultados

Se obtuvo una SPA con navegación entre inicio, lista de usuarios y formulario. La lista presenta usuarios recibidos desde la API y el formulario muestra la vista para ingresar un nuevo usuario.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a organizar estructuras HTML semánticas y a trasladar esa organización a componentes reutilizables. Reforcé cómo se comparten datos con props y cómo children permite componer componentes con contenido anidado.

También aprendí a estructurar una SPA con React y Vite, navegar entre vistas y consumir datos desde una API. Observar el renderizado del lado del cliente me ayudó a comprender cómo las actualizaciones de la aplicación se reflejan en el DOM.

¿Cómo aprendí?

Aprendí mediante ejercicios de composición: primero organicé el contenido con elementos semánticos y luego lo distribuí entre componentes, pasando datos y contenido anidado.

Para la SPA, probé las diferentes vistas y la consulta de usuarios desde el navegador. Las DevTools y los mensajes de la consola permiten revisar solicitudes de red, errores y el comportamiento de la interfaz al navegar.
