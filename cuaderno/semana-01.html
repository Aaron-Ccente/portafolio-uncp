Fundamentos de la Tecnología Web

Registro de los temas aprendidos, actividades de laboratorio y reflexión correspondiente a la primera semana.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Desarrollo Web

El desarrollo web comprende el proceso de crear sitios y aplicaciones que funcionan mediante un navegador web.

Frontend

Se enfoca en la parte visual e interactiva que el usuario puede observar y utilizar.

Backend

Se encarga de la lógica, procesamiento de información y comunicación con bases de datos y servicios.

Tema 02

HTML, CSS y JavaScript

Son tecnologías fundamentales para la construcción de páginas y aplicaciones web.

HTML

Define la estructura y el contenido de una página web.

CSS

Permite diseñar y dar estilo a los elementos de una página web.

JavaScript

Añade lógica, comportamiento e interactividad a las páginas web.

02

LABORATORIO

Actividades de laboratorio

Actividad 01

Infografía Técnica - Propuesta de Hosting para Proyecto Web Corporativo

Descripción

Se realizó en equipos, una propuesta de comparación entre servicios de nube para Textiles Andinos. Para nuestro caso, hicimos la comparación entre los servicios de AWS y GCP.

Procedimiento

  1. Buscamos los posibles servicios de nube a comparar.
  2. Investigar costos de servicios base para el sistema a implementar (AWS y GCP)
  3. Definir propuesta basado en costos y escalabilidad.
  4. Exponer propuesta.

Resultados

En base a la investigación en infraestructura y usando una calculadora de costos de AWS y GCP, obtuvimos un resultado a favor de GCP.

Actividad 02

Diseño de Tarjeta de Presentación Personal

Descripción

Se realizó el diseño de una tarjeta de presentación personal, incluyendo información básica, datos de contacto y una breve descripción de mi perfil.

Procedimiento

  1. Definir la información que se incluiría en la tarjeta.
  2. Seleccionar una estructura y diseño adecuados para la presentación.
  3. Organizar los elementos visuales y la información personal.
  4. Revisar y presentar el diseño final.

Resultados

Se obtuvo una tarjeta de presentación personal con información relevante sobre mi perfil y datos de contacto, aplicando una distribución clara y un diseño sencillo.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Durante esta semana aprendí conceptos básicos del desarrollo web y conocí algunas alternativas de servicios de nube. También aprendí a organizar información y presentarla de manera clara mediante una infografía y una tarjeta de presentación personal.

¿Cómo aprendí?

Aprendí mediante la investigación, el desarrollo de las actividades y la práctica. La elaboración de la infografía y la tarjeta de presentación me permitió aplicar los conceptos de forma práctica y mejorar la manera en que organizo y presento la información.
