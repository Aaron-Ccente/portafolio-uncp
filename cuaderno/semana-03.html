APRENDIZAJE

Temas aprendidos

Tema 01

Diseño de páginas web con HTML y Tailwind

HTML permite crear la estructura de una página web mediante etiquetas, mientras que Tailwind CSS facilita el diseño utilizando clases de utilidad.

Diseño responsivo

Permite adaptar la página a diferentes tamaños de pantalla, como celulares, tablets y computadoras.

Tema 02

BOOTSTRAP Y TAILWINDCSS POR CDN

Bootstrap y TailwindCSS son frameworks utilizados para diseñar y personalizar páginas web de manera rápida. Ambos permiten aplicar estilos sin tener que escribir todo el CSS desde cero.

BOOTSTRAP

Es un framework que proporciona componentes prediseñados como botones, tarjetas, formularios, tablas y sistemas de diseño responsivo.

TAILWINDCSS

Permite crear diseños utilizando clases de utilidad directamente en las etiquetas HTML, facilitando la personalización de colores, tamaños, espacios y distribución.
