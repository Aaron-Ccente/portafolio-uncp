SEMANA 05

Creación de proyectos con React

Registro de la creación de proyectos con Create React App, Vite y Next.js, junto con una práctica de React enfocada en el renderizado del lado del cliente y la composición de componentes.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Creación de proyectos React

Se exploraron distintas herramientas para iniciar aplicaciones: Create React App, Vite y Next.js. Cada alternativa organiza el proyecto y ofrece comandos para iniciar el servidor de desarrollo y preparar la aplicación.

Herramientas y estructura

Se reconocieron archivos y carpetas habituales, como src, public y package.json, y se ejecutaron los proyectos en local para observar sus páginas iniciales.

Tema 02

Framework JavaScript: React

React permite construir interfaces mediante componentes reutilizables. Cada componente representa una parte de la interfaz y puede combinarse con otros para formar una aplicación.

Componentes

La interfaz se organiza en unidades independientes, facilitando la separación de responsabilidades, la reutilización y el mantenimiento del código.

Tema 03

Client-Side Rendering (CSR)

En el renderizado del lado del cliente, el navegador carga la aplicación y ejecuta JavaScript para construir y actualizar la interfaz. React mantiene sincronizada la vista con los datos de los componentes.

Actualización de la interfaz

Este enfoque permite responder a cambios e interacciones sin recargar toda la página, y se diferencia del renderizado realizado en el servidor.

Tema 04

JSX, Props y Children

JSX ofrece una sintaxis similar a HTML para describir la interfaz dentro de JavaScript. Las props permiten enviar datos desde un componente padre hacia uno hijo.

Composición con children

La propiedad especial children contiene el contenido anidado entre las etiquetas de un componente. Esto permite crear componentes contenedores y reutilizar estructuras con contenido variable.

LABORATORIO

Actividades de laboratorio

Semana 05 · Actividad 01

Creación de proyectos

Descripción

Se crearon y ejecutaron proyectos de inicio con Create React App, Vite y Next.js para reconocer sus estructuras y comparar sus páginas iniciales y entornos de desarrollo.

Procedimiento

  1. Preparar el espacio de trabajo para los proyectos.
  2. Crear una aplicación inicial con Create React App y ejecutarla en el servidor local.
  3. Crear y ejecutar otro proyecto con Vite, observando su plantilla y recarga durante el desarrollo.
  4. Iniciar un proyecto con Next.js y revisar su estructura inicial.
  5. Comparar los archivos y las páginas de inicio de cada alternativa.

Resultados

Se obtuvieron proyectos funcionales en local con las tres herramientas. Las capturas muestran la configuración del espacio de trabajo y las pantallas iniciales de Create React App, Vite y Next.js.

Semana 05 · Actividad 02

Framework JS (React)

Descripción

Se desarrolló una interfaz temática de centro de control para la sonda Voyager 1, aplicando React, Client-Side Rendering (CSR), JSX y composición de componentes con Props y Children.

Procedimiento

  1. Definir la información principal que mostraría el panel de la misión.
  2. Organizar la interfaz en componentes para el encabezado y las tarjetas de métricas.
  3. Escribir la estructura visual con JSX y pasar los datos de cada tarjeta mediante props.
  4. Reutilizar un componente contenedor para mostrar contenido anidado mediante children.
  5. Ejecutar la aplicación en el navegador y revisar el resultado renderizado por React en el cliente.

Resultados

Se obtuvo un panel de control de Voyager 1 con información de distancia, retardo de señal, velocidad, potencia y estado del inspector. La interfaz presenta datos organizados en componentes visuales reutilizables.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a crear proyectos con Create React App, Vite y Next.js, y a reconocer diferencias en sus estructuras y páginas iniciales. También comprendí cómo React organiza una interfaz mediante componentes y cómo se renderiza en el cliente.

En la práctica reforcé el uso de JSX, el paso de información con props y la composición de componentes utilizando children. Estos conceptos ayudan a mantener una interfaz ordenada y reutilizable.

¿Cómo aprendí?

Aprendí creando los proyectos y ejecutándolos en el navegador para observar sus plantillas y estructuras. Luego apliqué los conceptos de React al separar el panel de Voyager 1 en partes visuales y construirlas de forma progresiva.

La práctica con props y children me permitió entender cómo pasar datos y contenido entre componentes, mientras que revisar la aplicación en el navegador ayudó a relacionar el código JSX con la interfaz resultante.
