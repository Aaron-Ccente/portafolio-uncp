01

APRENDIZAJE

Temas aprendidos

Tema 01

Integración de JavaScript y estructura del DOM

Se aprendió a integrar JavaScript o TypeScript en una página web mediante archivos separados como app.js o app.ts, utilizando defer para controlar la carga del script y trabajar correctamente con la estructura del DOM.

Manipulación del DOM

Se utilizaron métodos como querySelector(), addEventListener() y classList.toggle() para seleccionar elementos, responder a eventos y modificar dinámicamente la interfaz sin depender de frameworks o librerías externas.

Tema 02

Funciones, IIFE y closures en JavaScript

Se estudiaron las IIFE para aislar el alcance de las variables, los closures para conservar información entre diferentes ejecuciones y las arrow functions para implementar manejadores de eventos y funciones de forma más concisa.

Estado mediante closures

Los closures permiten mantener el estado de una animación entre diferentes frames, evitando que los valores necesarios para el movimiento se pierdan durante la ejecución del programa.

Tema 03

Canvas y animaciones con requestAnimationFrame

Se aprendió a utilizar el elemento Canvas y su contexto 2D para crear gráficos mediante funciones como arc(), fillRect() y stroke().

Loop de renderizado

Se implementaron animaciones utilizando requestAnimationFrame(), considerando el Event Loop, el proceso de renderizado y la sincronización con la frecuencia de actualización de la pantalla. Para lograr un movimiento uniforme se utilizó delta time (dt) en lugar de setInterval().

Tema 04

Depuración y optimización del rendimiento

Se aprendió a analizar el rendimiento de una aplicación utilizando herramientas de desarrollo como Console Profiler, métricas de FPS y Memory Snapshot.

Optimización y gestión de memoria

Se identificaron problemas relacionados con listeners huérfanos, nodos desconectados (detached nodes) y acumulación innecesaria de memoria. También se estudió el uso de cancelAnimationFrame() y las métricas de rendimiento para mejorar la ejecución de las animaciones.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a integrar JavaScript y TypeScript en una página web para controlar y modificar dinámicamente los elementos del DOM. También comprendí el funcionamiento de las IIFE, los closures y las funciones flecha, especialmente para mantener el estado de una animación entre diferentes frames.

Además, aprendí a utilizar Canvas con su contexto 2D para realizar dibujos y animaciones mediante requestAnimationFrame(), utilizando delta time para conseguir un movimiento más uniforme. Finalmente, reforcé conocimientos sobre el Event Loop, el proceso de renderizado y las técnicas de depuración y optimización del rendimiento.

¿Cómo aprendí?

Aprendí principalmente mediante la práctica, implementando cada funcionalidad de manera progresiva y observando cómo interactúan JavaScript, el DOM y el navegador. Realicé pruebas con eventos, manipulación de clases, variables CSS y animaciones utilizando Canvas para comprender mejor el comportamiento de la aplicación.

También utilicé las herramientas de desarrollo del navegador para identificar errores y analizar el rendimiento, revisando métricas como los FPS, el uso de memoria y el comportamiento de los listeners. Esto me permitió comprender que una aplicación no solo debe funcionar, sino también utilizar adecuadamente los recursos del navegador.
