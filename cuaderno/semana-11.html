SEMANA 11

Django 5 y arquitectura MTV

Construcción de aplicaciones web con Django, enrutamiento, vistas, plantillas, ORM, migraciones y persistencia de datos en SQLite.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Arquitectura Model-Template-View

Django organiza la aplicación mediante el patrón MTV. Los modelos representan los datos, las plantillas generan la presentación y las vistas coordinan las solicitudes. El proyecto y las aplicaciones mantienen una estructura modular y configurable.

Tema 02

URLs y vistas basadas en funciones y clases

El archivo urls.py relaciona rutas con vistas y permite asignar nombres reutilizables. Las FBV ofrecen lógica explícita y las CBV reutilizan comportamientos comunes, como ListView para mostrar colecciones de registros.

Tema 03

Plantillas, ORM y persistencia

Las plantillas permiten herencia, bloques, ciclos, condicionales y filtros. El ORM traduce operaciones Python a consultas sobre SQLite y las migraciones mantienen sincronizado el esquema con los modelos definidos.

ACTIVIDADES

Desarrollo web con Django

Semana 11 · Actividad 01

Configuración y primera aplicación Django

Descripción

Se configuró un proyecto Django 5.x dentro de un entorno virtual con Python 3.11 o superior. La aplicación aplica el patrón MTV, usa un sistema de rutas y prepara la configuración para plantillas, modelos, formularios, panel administrativo y sesiones.

El trabajo comprende la instalación del framework, la ejecución del servidor, una vista de bienvenida y el acceso al administrador para crear registros desde la interfaz gráfica.

Procedimiento

  1. Crear y activar un entorno virtual, instalar Django 5 y generar el proyecto y la aplicación correspondientes.
  2. Configurar settings.py, la estructura de plantillas y los archivos urls.py del proyecto y de la aplicación.
  3. Implementar vistas basadas en funciones y clases y validar el ciclo solicitud-respuesta desde el navegador.
  4. Ejecutar makemigrations y migrate para crear las tablas requeridas por Django y por los modelos personalizados.
  5. Comprobar el servidor, iniciar sesión en Django administration y registrar un producto desde el panel.

Resultados

Las capturas verifican la instalación, la página de inicio, el acceso administrativo y el formulario para añadir un producto con nombre, descripción, precio, stock y estado.

Semana 11 · Actividad 02

Catálogo de Productos Tecnológicos

Descripción

Se desarrolló un catálogo con arquitectura MTV y una aplicación separada del proyecto principal. Incluye una vista de bienvenida basada en FBV y un catálogo construido con la CBV ListView.

El modelo Producto registra nombre, descripción, precio, categoría, stock y estado activo. Los datos persisten en SQLite y la plantilla utiliza herencia, rutas nombradas, filtros, ciclos y condicionales para presentar los productos.

Procedimiento

  1. Separar el proyecto Django de la aplicación Catálogo y configurar settings.py con las rutas de plantillas.
  2. Crear una ruta principal con una FBV de bienvenida y una ruta /catalogo/ asociada a ListView.
  3. Diseñar base.html y catalogo.html con herencia, bloques, encabezado, pie de página y enlaces nombrados.
  4. Definir el modelo Producto, crear las migraciones y cargar los datos desde SQLite mediante el ORM.
  5. Filtrar el QuerySet, ordenar los productos y comprobar las categorías y el estado de stock desde la interfaz.

Resultados

La evidencia muestra la página principal, el listado completo de diez productos, el filtro por categoría y un ejemplo de consulta filtrada que muestra solo los discos SSD disponibles.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a estructurar una aplicación Django siguiendo el patrón MTV, relacionar URLs con vistas FBV y CBV y usar modelos con el ORM para consultar y persistir datos. También comprendí cómo las plantillas reutilizables permiten presentar información real desde SQLite.

¿Cómo aprendí?

Practiqué desde la instalación y configuración inicial hasta la creación de migraciones y registros administrativos. Después desarrollé el catálogo completo y probé filtros por categoría y disponibilidad, verificando que las plantillas mostraran los datos obtenidos por Django.
