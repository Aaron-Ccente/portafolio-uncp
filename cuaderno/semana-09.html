SEMANA 09

Formularios, sesiones y despliegue web

Desarrollo y despliegue de formularios con PHP y JSP, manejo de sesiones y revisión del ciclo HTTP y de medidas básicas de seguridad para aplicaciones web.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Formularios y procesamiento con PHP

Un formulario HTML envía datos al servidor mediante una solicitud POST. PHP recibe los valores, los valida y sanitiza antes de usarlos. En el ejercicio de préstamo se procesan datos del lector, correo, libro, categoría y duración, y se calcula la fecha de devolución.

Tema 02

Sesiones y plantillas JSP

$_SESSION permite conservar información asociada a la sesión entre solicitudes, como una colección de contactos registrados. En JSP, los parámetros de request procesan el formulario y session mantiene los registros para presentarlos en una respuesta estructurada.

Tema 03

Ciclo HTTP y seguridad básica

El navegador envía una solicitud HTTP al servidor, que ejecuta el backend y devuelve una respuesta para renderizar. Validar el método y los datos recibidos, escapar la salida con htmlspecialchars o <c:out> y manejar errores 4xx y 5xx ayuda a evitar fallos y prevenir XSS.

02

ACTIVIDADES

Formularios con PHP y JSP

Semana 09 · Actividad 01

Formulario de préstamo de libros en PHP

Descripción

Se desarrolló un formulario web para registrar solicitudes de préstamo en una biblioteca. El lector ingresa sus datos, el título del libro, la categoría y los días del préstamo. El servidor procesa la solicitud y muestra la información registrada junto con la fecha de devolución.

La actividad también aborda el levantamiento del servidor para ejecutar PHP y la importancia de validar y sanitizar los datos recibidos.

Procedimiento

  1. Preparar un formulario HTML con campos para lector, correo, libro, categoría y duración del préstamo.
  2. Enviar la información al servidor y comprobar que la solicitud utiliza el método esperado.
  3. Validar los campos y el rango de días, y sanitizar los datos antes de presentarlos.
  4. Procesar el préstamo y mostrar una confirmación con los datos ingresados y la fecha de devolución.

Resultados

Se evidencia el formulario de préstamo y la página de confirmación con los datos del lector, el libro, la categoría, los días solicitados y la fecha de devolución.

Semana 09 · Actividad 02

Registro de contactos con PHP y JSP

Descripción

Se comparó el procesamiento de un formulario de contacto en PHP y JSP. En la versión PHP, el formulario envía nombre y correo a un script que registra los datos en $_SESSION y muestra la lista de contactos. En JSP se procesa el formulario con los datos de request y se conserva la información en la sesión para devolver una respuesta estructurada.

La actividad relaciona el envío del formulario con el ciclo de una solicitud HTTP y considera validación de entradas, prevención de XSS y diferencias entre ambos entornos.

Procedimiento

  1. Crear un formulario de contacto con nombre y correo y enviarlo al backend mediante POST.
  2. Procesar los parámetros y guardar el contacto en la sesión actual en PHP o JSP.
  3. Renderizar los registros en una tabla y escapar los valores dinámicos antes de insertarlos en el HTML.
  4. Revisar la solicitud y la respuesta en las herramientas de red del navegador.
  5. Comparar PHP y JSP considerando ciclo de vida, despliegue, rendimiento, gestión de estado y ecosistema.

Resultados

Las evidencias muestran los formularios PHP y JSP, el registro de un contacto en la sesión y la solicitud procesar.jsp observada en la pestaña de red del navegador.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a conectar formularios HTML con un backend y a conservar datos entre solicitudes mediante sesiones. También comprendí que validar entradas, controlar el método HTTP y escapar la salida son pasos esenciales para procesar información de manera segura.

¿Cómo aprendí?

Comparé implementaciones en PHP y JSP, seguí el recorrido desde el envío del formulario hasta la respuesta del servidor y observé la solicitud desde las herramientas de desarrollo del navegador. Las evidencias ayudaron a relacionar el código del servidor con lo que recibe y muestra el cliente.
