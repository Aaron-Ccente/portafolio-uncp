SEMANA 07

Hooks y gestión de estado en React

Evaluación de un sistema de gestión de biblioteca y laboratorios para aplicar Hooks nativos y personalizados, controlar el estado complejo y optimizar el renderizado de aplicaciones React.

01

APRENDIZAJE

Temas aprendidos

Tema 01

Ciclo de renderizado y efectos

Los Hooks permiten incorporar estado y otros comportamientos a componentes funcionales. useEffect ejecuta efectos secundarios después del renderizado y su función de limpieza ayuda a liberar recursos, cancelar suscripciones o retirar eventos cuando cambian las dependencias o se desmonta el componente.

Tema 02

Estado compartido y optimización

useContext comparte preferencias y datos entre componentes sin pasar props por todos los niveles. useMemo y useCallback permiten memorizar cálculos y funciones cuando es necesario evitar trabajo o renders innecesarios. useRef conserva una referencia mutable o permite acceder a un nodo del DOM sin provocar un renderizado.

Tema 03

Estado complejo y Hooks personalizados

useReducer organiza transiciones de estado relacionadas mediante acciones, mientras que un Hook personalizado encapsula lógica reutilizable. React DevTools Profiler ayuda a observar los renders y analizar el efecto de las optimizaciones.

02

ACTIVIDADES

Examen parcial y laboratorios

Semana 07 · Actividad 01

Examen parcial: Sistema de Gestión de Biblioteca Universitaria

Descripción

Se planteó un sistema web para que la Biblioteca Central administre el préstamo de libros a estudiantes y docentes. Los administradores gestionan libros, categorías y préstamos; los usuarios registrados pueden buscar libros, solicitar préstamos y consultar su historial.

Toda la información se almacena en Local Storage, simulando la persistencia de un sistema empresarial sin depender de bases de datos externas. El sistema también genera un comprobante digital por cada préstamo.

Requerimientos principales

  1. Presentar un catálogo de libros con búsqueda por título, autor o ISBN, filtro por categoría y disponibilidad de ejemplares.
  2. Permitir que un usuario registrado solicite el préstamo de un libro disponible y consulte su historial de préstamos.
  3. Proporcionar módulos de administración para registrar, editar y eliminar libros, categorías y usuarios, además de gestionar préstamos e inventario.
  4. Persistir los datos del sistema en Local Storage y actualizar el stock al registrar un préstamo.
  5. Generar y mostrar un comprobante digital con los datos del usuario, el libro y el préstamo realizado.

Resultados

Las capturas muestran el catálogo bibliográfico, el módulo administrativo de libros y la gestión de usuarios para el sistema de biblioteca.

Semana 07 · Actividad 02

Laboratorio: Hooks nativos y ciclo de renderizado

Descripción

El laboratorio profundiza en el ciclo de renderizado de React y el uso estratégico de Hooks nativos. Se aplican useEffect con sus dependencias y limpieza, useContext para el estado global, useMemo y useCallback para optimizar cálculos y funciones, y useRef para conservar referencias sin provocar renders.

También se refactoriza lógica compleja con useReducer y se encapsulan comportamientos reutilizables en Hooks personalizados. El flujo de re-renderizados se valida con React DevTools Profiler.

Procedimiento

  1. Implementar la interfaz de exploración de personajes con búsqueda, filtros y acciones para gestionar favoritos.
  2. Compartir preferencias de tema con useContext y usar useEffect para sincronizar o limpiar efectos secundarios.
  3. Aplicar useMemo y useCallback en operaciones derivadas y handlers; usar useRef para una referencia mutable o un elemento del DOM.
  4. Organizar las transiciones de estado relacionadas mediante useReducer y extraer lógica común a Hooks personalizados.
  5. Medir el flujo de renders con React DevTools Profiler y verificar que las optimizaciones respondan a cambios relevantes.

Resultados

La interfaz de exploración permite buscar personajes, filtrarlos y administrar favoritos, con una preferencia de tema compartida. El análisis con Profiler permite revisar el comportamiento de los componentes durante las interacciones.

Semana 07 · Actividad 03

Laboratorio: Dashboard de Gestión con Estado Complejo

Descripción

Se desarrolla un dashboard de tareas que combina estado complejo y preferencias globales. useReducer administra las acciones de agregar, eliminar, filtrar y ordenar tareas, mientras que useState controla el estado local de la interfaz.

El dashboard integra useContext para el tema o las preferencias, useEffect para sincronizarlas con Local Storage y limpiar efectos, useMemo para derivar la lista filtrada y ordenada, useCallback para los handlers y useRef para enfocar el campo de entrada sin generar un render adicional. La persistencia reutilizable se encapsula en un Hook como useLocalStorage o useDebounce.

Procedimiento

  1. Modelar con useReducer la colección de tareas y sus operaciones de agregar, eliminar, filtrar y ordenar.
  2. Gestionar con useState los controles de interfaz y con useContext el tema claro u oscuro o las preferencias del usuario.
  3. Sincronizar preferencias con Local Storage mediante useEffect y definir la limpieza de los efectos que la requieran.
  4. Derivar resultados con useMemo, estabilizar handlers con useCallback y enfocar el campo de nueva tarea con useRef.
  5. Crear un Hook personalizado de persistencia o debounce y comprobar los renders y la interacción del dashboard.

Resultados

El panel presenta el estado de las tareas, filtros por estado, búsqueda, criterios de ordenamiento, resumen y preferencias visuales. También permite observar el contador de renders y generar tareas de prueba para analizar el rendimiento con Profiler.

03

REFLEXIÓN

Reflexión personal

¿Qué aprendí?

Aprendí a elegir Hooks según la responsabilidad de cada parte de una aplicación: manejar estado local o complejo, compartir preferencias, sincronizar efectos y optimizar cálculos y callbacks. También reforcé el uso de Local Storage para conservar datos y preferencias en el navegador.

El examen parcial permitió aplicar estos conocimientos en el contexto de una biblioteca universitaria, mientras que los laboratorios mostraron cómo organizar interfaces interactivas y observar sus re-renderizados con React DevTools Profiler.

¿Cómo aprendí?

Aprendí mediante la implementación de casos concretos: un sistema de préstamos con roles y persistencia local, una interfaz de exploración y un dashboard de tareas con filtros y ordenamiento. Separar el estado de la interfaz del estado de los datos ayudó a elegir la herramienta adecuada para cada necesidad.

Finalmente, observé los cambios de renderizado en las herramientas de desarrollo y revisé cómo las dependencias, la limpieza de efectos y las optimizaciones influyen en la actualización de los componentes.
