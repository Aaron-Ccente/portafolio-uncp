Actividad 02
1.	Despliegue PHP: Formulario HTML → registro.php → validación, sanitización, almacenamiento en $_SESSION, respuesta con tabla de registros.
2.	Despliegue JSP: Formulario JSP → registro.jsp → manejo de request, session, uso de <c:forEach> o <% %>, respuesta estructurada.
3.	Ciclo HTTP: Documentar flujo: Cliente → DNS → TCP/IP → HTTP Request → Server → Backend → Response → Render.
4.	Seguridad Básica: Prevención XSS (htmlspecialchars/<c:out>), validación de métodos POST, manejo de errores 4xx/5xx.
5.	Comparativa Técnica: Matriz PHP vs JSP (ciclo de vida, rendimiento, despliegue, gestión de estado, madurez ecosistema).
